# Personal Portfolio Website

This is my personal portfolio website built using **React** and **Vite**. It's designed to showcase my projects, skills, and experience as a developer in a fast, minimal, and responsive way.

## Tech Stack

- **React** – Modern UI library for building fast user interfaces  
- **Vite** – Lightning-fast build tool with native ESM support  
- **ESLint** – Linting and code quality enforcement  
- **Framer Motion** – Smooth animations and transitions  
- **React Icons** – Icon library for consistent visuals

## Setup & Development

```bash
# 1. Clone the repo
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev

# 4. Build for production
npm run build
```
